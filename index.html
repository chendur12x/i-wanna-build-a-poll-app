Option 1: GitHub Actions Cron (Recommended)

100% FREE

Runs on GitHub's cloud every 5 minutes forever. No credit card required.

Already generated in repo!
3-Step Free Setup:
Step 1: Connect this project to your GitHub repository by tapping the GitHub mark at the top of the chat.
Step 2: In your GitHub repo, go to Settings → Secrets and variables → Actions and add your secrets:
  • TELEGRAM_BOT_TOKEN & TELEGRAM_CHAT_ID
  • NTFY_TOPIC (e.g. dune3-chennai-imax)
  • DISCORD_WEBHOOK_URL (optional)
  • CITY (default: chennai)
  • CINEMA_FILTER (default: palazzo, luxe, basera)
Step 3: The workflow file .github/workflows/dune-imax-poller.yml is already created in this project and activates automatically!
Workflow File: .github/workflows/dune-imax-poller.yml 
name: Dune 3 IMAX Ticket Radar Poller
on:
  schedule:
    - cron: '*/5 * * * *' # Every 5 minutes 24/7
  workflow_dispatch:

jobs:
  poll-tickets:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - name: Run Poller
        env:
          MOVIE_KEYWORD: ${{ secrets.MOVIE_KEYWORD || 'dune' }}
          CITY: ${{ secrets.CITY || 'chennai' }}
          CINEMA_FILTER: ${{ secrets.CINEMA_FILTER || 'palazzo, luxe, basera' }}
          TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
          NTFY_TOPIC: ${{ secrets.NTFY_TOPIC }}
        run: node poller.js --once
